# Site config

Follow `scripts/site-config/rules.md`. It holds the workflow, the raw config format, the output schema and the mapping rules, and `CONTRIBUTING.md` holds the contributor's side (testing on the real site, the pull request).

Both files are tool-neutral and shared with other AI assistants through `AGENTS.md`. Put project knowledge there, not in this skill.
